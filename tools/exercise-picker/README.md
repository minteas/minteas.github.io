# 種目ランダムピッカー

トレーニング種目を「目的（下半身／ダイエット／お腹痩せ など）」で絞り込み、
ランダムに1種目表示するだけのシンプルなツール。リール企画のネタ出しに使う。

## 使い方

`index.html` をブラウザで開くだけ（サーバー不要）。

```bash
open tools/exercise-picker/index.html
```

1. 目的タグを選択（複数選択可。未選択なら全種目が対象）
2. 「ランダムに5種目表示」を押す（条件に合う種目が5件未満の場合は該当分のみ表示）
3. 「種目を追加・編集する」から新しい種目・タグを追加できる
4. 📌固定枠（`required: true`）にした種目は、絞り込み条件に一致する限り毎回の表示に必ず含まれる（初期状態では「サイドベント」が固定枠）

## データの保存について

- 追加・編集した内容はブラウザの localStorage に保存される（そのブラウザ内でのみ有効）。
- 他の端末・ブラウザでも同じデータを使いたい場合は「JSONで書き出し」→ 別環境で「JSONを読み込み」。
- `exercises.seed.json` は初期15種目のバックアップ。アプリ内の「初期データに戻す」で復元される内容と同じもの。
