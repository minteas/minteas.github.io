# 日々の記録

「その日やったこと」だけをサッと記録するツール。カレンダーで日にちを押すと、その日の記録が見られる。

## 使い方

`index.html` をブラウザで開くだけ（サーバー不要）。

```bash
open tools/task-tracker/index.html
```

1. カレンダーで日にちをクリックして選択する（初期状態は今日）
2. 入力欄にやったことを書いて「記録する」（1件ずつ、時刻つきで記録される）
3. 記録がある日はカレンダーに●印がつく
4. 削除は×ボタン。削除後しばらく画面下に「元に戻す」が出るので、誤削除してもすぐ戻せる

過去の日付を選んで記録を追加することもできる（書き忘れた日をあとから埋める用途）。

## データの保存について

- 記録はブラウザの localStorage に保存される（そのブラウザ内でのみ有効）。
