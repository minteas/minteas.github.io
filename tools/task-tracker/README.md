# タスクトラッカー

仕事のタスクを「内容・カテゴリ・優先度・期限」でサッと記録し、
完了チェックと絞り込みで消化状況を確認できるシンプルなToDoツール。

## 使い方

`index.html` をブラウザで開くだけ（サーバー不要）。

```bash
open tools/task-tracker/index.html
```

1. **タスクを追加**: 内容を入力し、カテゴリ（企画／撮影／編集／投稿／分析／その他）・
   優先度（高／中／低）・期限（任意）を選んで「追加」
2. **一覧**: 未完了タスクは期限が近い順→優先度順に並び、期限切れは赤枠で強調される。
   完了タスクはチェックすると打ち消し線になり、下に移動する
3. **フィルタ**: 「すべて／未完了／完了」で絞り込み
4. **操作ログ**: タスクの削除・完了済み一括削除・全クリアは自動で記録され、
   「元に戻す」でいつでも復元できる（最大100件保持）

## データの保存について

- 入力内容・ログはブラウザの localStorage に保存される（そのブラウザ内でのみ有効）。
- 「すべてクリア」しても操作ログには記録が残り続けるので、あとから復元できる。
