# ラウンドタイマー

格闘技・HIIT用のインターバルタイマー。運動時間・インターバル・ラウンド数を設定し、
フェーズの切り替わりごとに音でお知らせする。

## 使い方

`index.html` をブラウザで開くだけ（サーバー不要）。スマホでも使える。

```bash
open tools/interval-timer/index.html
```

1. プリセット（ボクシング／キックボクシング／テコンドー／テコンドー練習／MMA／柔術スパー／タバタ／HIIT 40/20）を選ぶか、各項目を −／＋ で調整（長押しで連続変更）
2. 「スタート」を押す（PCではスペースキーでも開始・一時停止）
3. タイマー画面で「一時停止」「スキップ」「終了」が使える

## 設定項目

| 項目 | 内容 |
|---|---|
| 運動時間 | 1ラウンドの長さ（1分までは5秒刻み、それ以上は15秒刻み） |
| インターバル | ラウンド間の休憩（0で休憩なし） |
| ラウンド数 | 1〜99 |
| 準備時間 | スタート前のカウント（0でスキップ） |
| 残り時間の合図 | 運動終了の◯秒前に拍子木を鳴らす（0でオフ） |

設定と音量はブラウザの localStorage に保存され、次回も同じ設定で開く。

## お知らせ音

| タイミング | 音 |
|---|---|
| 運動開始（準備・休憩から切り替わり） | 高い「ピーッ」＋ゴング1回 |
| ラウンド終了（休憩開始） | 低いブザー「ブーッ」 |
| 残り時間の合図 | 拍子木（カチカチ） |
| 各フェーズ終了の3・2・1秒前 | ビープ |
| 全ラウンド終了 | ブザー＋ゴング3回 |

対応端末ではバイブレーションも併用する。

## 注意

- iPhone は消音スイッチがオンでも鳴るよう設定している（iOS 17 以降の Safari）。古い iOS では消音スイッチをオフにする。
- 実行中は画面スリープを防止する（Wake Lock 対応ブラウザのみ）。
- 時間は終了時刻ベースで計算しているので、タブが裏に回っても時間はずれない。ただし裏にある間は音が最大1秒ほど遅れることがある。
