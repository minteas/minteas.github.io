# 目標プランナー

月の目標を1つ立て、それを達成するために必要な数値目標を3つ設定して毎週の実績・手応えを確認しながら、
タスクを「緊急度 × 重要度」の4象限で優先度づけできるツール。

## 使い方

`index.html` をブラウザで開くだけ（サーバー不要）。

```bash
open tools/goal-planner/index.html
```

1. **今月の目標**: 1つだけ、大きな方向性を入力する
2. **今週の数値目標（①②③）**: 月の目標を達成するために必要な指標を3つ設定
   - 指標名・目標値・実績値を入力
   - 「◎ 効いている／△ 様子見／✕ 効いていない」で、月の目標への手応えを毎週更新する
3. **タスクの4象限**: 緊急度×重要度でタスクを仕分ける
   - 追加時に①②③のどの数値目標に効くタスクかを選択できる（バッジで表示）
   - 各タスクの「－／◎／△／✕」ボタンをクリックすると、そのタスクが実際に効いているかを記録できる（クリックで循環）
4. **操作ログ**: 削除・リセットは自動で記録が残り、あとから「元に戻す」で復元できる
   - タスクを×で削除しても、ログから元に戻せる
   - 「すべてクリア」で全データを消しても、ログから元の状態に戻せる
   - 「今週の数値目標を記録する」ボタンで、①②③の目標値・実績値・手応えをその時点のスナップショットとしてログに残せる（週ごとの推移を見返すのに使う）

## データの保存について

- 入力内容・ログはブラウザの localStorage に保存される（そのブラウザ内でのみ有効）。
- 「すべてクリア」で入力内容は消えるが、操作ログには記録が残り続ける（ログ自体は最大100件まで保持）。
