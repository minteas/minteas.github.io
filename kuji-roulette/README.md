# くじ引きルーレット

当たりの数と当たる確率（1％単位）を設定できる、くじ引き用のルーレットです。

- 「1等は〇〇」のように、等級ごとに景品の内容・確率・本数を設定できます（最大10種類）
- 当たりの確率を引いた残りが、自動で「はずれ」になります
- 本数がなくなった等級はルーレットから外れ、その分は「はずれ」になります
- 抽選には `crypto.getRandomValues` を使い、偏りのない乱数で当たりを決めます
- 設定と履歴はブラウザ（localStorage）に保存されます

公開URL: https://minteas.github.io/kuji-roulette/
